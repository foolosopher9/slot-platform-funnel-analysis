# Глава 2. Постановка задачи и исследовательские вопросы

## 2.1. Контекст

Онлайн-казино зарабатывают на ставках игроков, которых привлекают через платные, партнёрские и реферальные каналы, но сталкиваются с двумя проблемами: часть бюджета привлечения уходит на игроков, которые почти не играют, а часть аккаунтов используется с нарушением правил платформы, что создаёт регуляторные риски.

Рассматривается оператор, работающий на 10 европейских рынках (Сербия, Германия, Великобритания, Франция и др.) и привлекающий трафик через пять каналов (affiliate, organic, paid_search, paid_social, referral). Анализ заказывают две внутренние команды: маркетинг, который распределяет бюджет привлечения, и комплаенс, который следит за нарушениями правил. Данные описаны в главе 1, их ограничения — в разделе 1.5.

## 2.2. Цели и исследовательские вопросы

### Цель 1. Маркетинг

Определить, какие каналы привлечения и страны приводят более активных и больше ставящих игроков, на основе сессий и ставок за первые 90 дней после регистрации, чтобы перераспределить бюджет привлечения.

Качество игроков сегмента измеряется двумя метриками: долей активных игроков и медианным оборотом играющего игрока. Если обе метрики сегмента выше, чем у остальных, сегмент становится кандидатом на увеличение бюджета; если обе ниже — кандидатом на пересмотр (сокращение бюджета или смену таргетинга); при остальных сочетаниях бюджет остаётся прежним. Вердикт по странам дополнительно подтверждается на следующей когорте игроков, потому что механизма различий между странами нет. Стоимость привлечения в расчёт не входит, поэтому любой вердикт — кандидат, а не окончательное решение о бюджете.

| № | Вопрос | Метрика | Метод | Ожидаемый результат |
|---|---|---|---|---|
| 1 | Отличается ли доля активных игроков в каждом канале от остальных каналов? | Доля игроков с 3+ сессиями; все 8 000 игроков | Разница долей «канал − остальные каналы», 99% ДИ | Для каждого канала: выше, ниже или не отличается; вместе с вопросом 2 — вердикт по каналу |
| 2 | Отличается ли медианный оборот играющего игрока в каждом канале от остальных каналов? | Медиана суммы `bet_amount`; игроки с 1+ сессией | Разница медиан «канал − остальные каналы», бутстрэп по игрокам, 99% ДИ; проверка устойчивости без всплесков ставки | Для каждого канала: выше, ниже или не отличается; вместе с вопросом 1 — вердикт по каналу |
| 3 | Отличается ли доля активных игроков в каждой стране от остальных стран? | Доля игроков с 3+ сессиями; все 8 000 игроков | Разница долей «страна − остальные страны», 99% ДИ | Для каждой страны: выше, ниже или не отличается; вместе с вопросом 4 — вердикт-кандидат по стране |
| 4 | Отличается ли медианный оборот играющего игрока в каждой стране от остальных стран? | Медиана суммы `bet_amount`; игроки с 1+ сессией | Разница медиан «страна − остальные страны», бутстрэп по игрокам, 99% ДИ; проверка устойчивости без всплесков ставки | Для каждой страны: выше, ниже или не отличается; вместе с вопросом 3 — вердикт-кандидат по стране |

**Гипотезы**

Канал привлечения определяет намерение игрока, с которым он приходит на платформу, поэтому гипотезы о каналах опираются на это отраслевое знание.

- **H1:** доля активных игроков в organic, affiliate и paid_search выше, чем в остальных каналах, потому что игрок сам искал казино; в paid_social ниже, потому что игрок пришёл после импульсного клика по рекламе; в referral ниже, потому что игрок пришёл за бонусом, а не за игрой.
- **H2:** медианный оборот играющего игрока в organic, affiliate и paid_search выше, чем в остальных каналах, по тем же причинам; в paid_social и referral ниже.
- **Вопросы 3 и 4** — разведка: отраслевого механизма, который предсказывал бы различия между странами, нет, поэтому ожидается отсутствие различий.

### Цель 2. Комплаенс

Определить, в каких сегментах игроков чаще встречаются признаки нарушений правил платформы, на основе данных сессий за первые 90 дней после регистрации, чтобы решить, где нужен усиленный мониторинг, а где хватит единых правил.

Изучаются четыре признака: `geo_mismatch` (игра из другой юрисдикции), общее устройство у разных игроков (мультиаккаунтинг), темп спинов выше p99 (автоматизированная игра) и пересекающиеся сессии одного игрока (шеринг аккаунта). Игроки сегментируются по устройству (`device_pref`) и каналу привлечения, потому что для каждого из этих сегментов есть механизм нарушения: поездки связаны с mobile, реферальный бонус — с referral, скрипты — с desktop. Шеринг аккаунта изучается описательно, без сравнения сегментов: каждый случай пересекающихся сессий подозрителен сам по себе, поэтому результатом будет список игроков для прямой проверки. Признаки косвенные: они указывают на подозрение, а не доказывают нарушение.

## 2.3. Задачи

1. Рассчитать метрики каждого игрока за 90 дней после регистрации: число сессий, оборот, доли сессий с признаками нарушений.
2. Сравнить каждый канал и каждую страну с остальными по доле активных игроков и медианному обороту.
3. Сравнить устройства и каналы по частоте признаков нарушений.
4. Описать случаи пересекающихся сессий и составить список игроков для проверки.
5. Сформулировать рекомендации для маркетинга и комплаенса.

## 2.4. Определения и методы

**Окно наблюдения.** Все метрики игрока считаются за первые 90 дней после регистрации. В расчёт входят сессии с `sessions.start_ts < players.signup_ts + 90 дней` и спины с `spins.ts < players.signup_ts + 90 дней`. Окно одинаковое для всех, потому что без него ранние игроки получают преимущество в сессиях и обороте просто за счёт более долгого наблюдения (ограничение 4 в 1.5). 90 дней — самое длинное окно, которое полностью наблюдается у каждого из 8 000 игроков: последняя регистрация 30 октября 23:54, последние сессии начинаются 28 января.

**Принятые решения**

1. **Все 8 000 игроков входят в расчёт.** Игроки без сессий в окне получают нулевой оборот и считаются неактивными.
2. **Активный игрок — игрок с 3 и более сессиями в окне.** Порог N = 3 — медиана числа сессий на игрока за 90 дней. Она посчитана один раз по всем 8 000 игрокам, включая игроков без сессий, и зафиксирована до расчётов по исследовательским вопросам, поэтому порог нельзя подогнать под нужный результат.
3. **Играющий игрок — игрок с 1 и более сессией в окне.** Медианный оборот считается только по играющим игрокам.
4. **Различие признаётся по 99% доверительному интервалу.** Сегмент сравнивается со всеми остальными сегментами: для долей — разница долей, для медиан — разница медиан с бутстрэпом по игрокам. Уровень 99%, а не 95%, потому что сравнений много.
5. **Оборот считается со всплесками ставки.** Расчёт без всплесков — проверка устойчивости вывода.
6. **Тип вопроса.** «Проверка» — у вопроса есть гипотеза, основанная на отраслевом знании и записанная до расчётов. «Разведка» — отраслевого механизма, который предсказывал бы направление различий, нет; найденное различие нужно подтвердить на новых данных.

## 2.5. Ожидаемая ценность

Маркетинг получит для каждого канала и страны вердикт-кандидат — увеличить бюджет, оставить или пересмотреть — и сможет начать перераспределение бюджета с каналов, где обе метрики сходятся. Комплаенс получит список сегментов для усиленного мониторинга по каждому признаку нарушения и список игроков с пересекающимися сессиями для прямой проверки.
