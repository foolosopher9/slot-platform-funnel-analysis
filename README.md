# Анализ данных платформы онлайн-слотов

Портфолио-проект продуктового аналитика на синтетическом датасете [Online Slot Games - Players, Sessions & Spins](https://www.kaggle.com/datasets/monikamitrovic/online-slot-games-players-sessions-and-spins) (Kaggle, CC0): 8 000 игроков, 46 690 сессий и 4,6 млн спинов за 120 дней.

## О проекте

Оператор онлайн-казино работает на 10 европейских рынках и привлекает игроков через пять каналов. Анализ отвечает на вопросы трёх команд: маркетингу нужно понять, какие каналы и страны приводят более активных и больше ставящих игроков; комплаенсу — у каких игроков есть признаки нарушения правил (игра из другой локации, общее устройство, одновременные сессии); команде ответственной игры — повышают ли игроки резко ставку после крупного проигрыша. Активность, оборот и игра из другой локации считаются за одинаковое окно 90 дней после регистрации, общее устройство и одновременные сессии — за весь период. Сегменты сравниваются по доле активных игроков и медианному обороту с 99% доверительными интервалами.

## Как воспроизвести

Нужен PostgreSQL с клиентскими утилитами (`psql`, `createdb`, `pg_isready`); сервер должен быть запущен.

1. Скачайте датасет с Kaggle и положите `players.csv`, `sessions.csv` и `spins.csv` в `data/raw/`.
2. Соберите базу:
   ```bash
   ./scripts/load.sh
   ```
   При первом запуске скрипт создаёт базу `igaming`, при повторных пересобирает таблицы с нуля. Другое имя базы: `DB=my_db ./scripts/load.sh`.
3. Получите цифры главы 1:
   ```bash
   psql -d igaming -f sql/03_quality_checks.sql
   psql -d igaming -f sql/04_profiling.sql
   psql -d igaming -f sql/05_pace_check.sql
   ```
4. Получите цифры главы 2:
   ```bash
   psql -d igaming -f sql/06_window.sql
   psql -d igaming -f sql/07_geo_mismatch_rate.sql
   psql -d igaming -f sql/08_loss_window_check.sql
   ```
